YOUR ROUTE

我的成长路线是什么？

六个阶段不是六门必须连续购买的课，而是一条能力逐步被学习和实践验证的路径。点击阶段，看清每一步。

G1

建立心理学、法律伦理、测量、识别转介的共同底座；当前首期以心理咨询流程、会谈技术和模拟演练为主线。

完整“心理入门”还包含什么？

完整的心理入门路径还包括心理讲座、心理团辅和项目辅助等任务初体验，可以逐步形成教案与试讲、团体方案与协同演练等作品。

你当前了解的首期课程聚焦心理咨询主线实训；其他方向可在后续学习中按适配继续补足。初阶可以从课程助教、活动协助、项目助理等任务开始了解实际工作。

下一步：完成入门作品与考核后，继续进入 G2 心理实务，在主责人员和督导支持下接触真实任务，再按适配选择方向专修。
阶段进阶不只看“上完课”＝课程学习＋作品考核＋真实实践＋督导评价＋伦理记录

当前第一步 · G1 心理入门

从首期「一证一岗」心理咨询师实训开始

你不需要在报名前就把长期方向一次选死。先用线上系统理论与线下 5 天咨询实训建立共同底座，完成咨询流程、会谈技术和模拟演练；再根据作品、考核与适配反馈进入 G2 心理实务，逐步选择咨询、讲师、团辅或项目方向。

关于首期，六个问题直接回答

把学习内容、训练方式、成果与后续路径一次说清。

01 · 学什么

共同底座＋咨询入门

线上学习心理学、法律伦理、心理测量、识别转介等基础；线下围绕咨询流程、基本会谈和模拟／综合演练展开，先建立理解心理服务和完成入门任务的能力。

02 · 怎样练

示范、跟练、纠偏、复盘

通过教师示范、角色扮演、跟练纠偏和综合演练，把知识变成可观察的动作。练习会留下阶段任务作品与反馈，不停留在“听过、记过”。

03 · 如何考核

看任务、作品与现场表现

考核关注课程任务、入门作品以及模拟／演练中的实际表现，包括基本会谈、识别转介和伦理要求；考核结果与适配反馈进入个人成长档案，而不只看出勤。

04 · 结业后能做什么

先完成入门任务，再连接适配实践

你能够运用共同心理学底座完成咨询入门模拟与演练，并带着作品、考核结果和路径建议继续进阶。在适配项目与支持条件具备时，可从课程助教、活动协助、项目助理、筛查／资料收集助理等任务开始积累。

05 · 后续有哪些路径

先实务，再形成主专业

G2 在主责专业人员与督导支持下接触真实任务；G3 按适配选择咨询、讲师、团辅或项目方向专修；之后可向专业精进、课程研发、项目管理、督导与师资发展。

06 · 需要投入什么

线上学习＋线下 5 天＋练习复盘

除了课时，还需要为演练、作品和复盘留出时间，并愿意接受反馈、遵守伦理。开班时间、费用、证书发证主体与报名方式会在当期招生简章中列明，报名沟通时也会结合你的经历、时间与目标梳理路径。

02

CAREER DIRECTIONS

我能去哪里、怎样开始？

四条方向不是必须在起点一次选死的单选题。先看工作内容与你的经历怎样衔接，再从 G1 共同底座出发，在 G2 实务中继续确认适配，逐步形成一项主专业＋若干辅助能力。

01

心理咨询

通过个体、家庭及相关心理服务，支持来访者面对困扰。

如果你愿意：长期训练倾听、会谈与个案概念化，并在督导中持续改进，可以重点了解这条线。

初阶入口初访 / 筛查助理
看我怎样从这里起步

初访/筛查助理 → 受督导实践 → 短程咨询 → 中长程与专项

你的第一段：首期就以心理咨询为主线，先练初访流程、基本会谈与识别转介；G2 在主责专业人员和督导支持下参与适配任务，G3 再进入咨询方向专修，逐步向短程咨询及更复杂服务发展。

02

心理讲师

开展心理科普、家长课堂、教师或企业培训。

如果你有：教学、表达、课程组织经验，或喜欢把复杂知识讲清楚，这条线可能更能接住你的优势。

初阶入口课程助教
看我怎样从这里起步

助教 → 协同/模块讲师 → 标准讲师 → 专题讲师 / 课程研发

你的第一段：先用 G1 补足心理学与伦理底座，再通过讲师实务训练需求分析、教案课件和模块试讲。可以从课程助教、指定模块试讲开始，逐步走向标准讲师、专题讲师和课程研发；这条线不要求你先成为独立咨询师。

03

心理团辅

带领心理教育团体、成长团体与主题活动。

如果你喜欢：组织活动、带动团体互动，并愿意学习方案设计与过程管理，可以重点了解这条线。

初阶入口活动协助
看我怎样从这里起步

活动协助 → 协同带领 → 结构化团体主带 → 专项团体

你的第一段：在共同底座上继续学习团体方案、协同演练、风险识别与复盘。先通过活动协助和指定环节协同积累现场经验，再按作品、表现与反馈逐步走向结构化心理教育团体主带。

04

测评访谈与项目

参与筛查、访谈、项目执行与项目管理。

如果你擅长：组织、沟通、数据、台账和多方协作，原有经历可以成为这条线的起点优势。

初阶入口项目助理
看我怎样从这里起步

项目助理 → 测评/访谈专员 → 项目专员 → 项目经理

你的第一段：先利用心理测量、资料收集与访谈基础，补上项目交付、服务记录、数据台账和效果评估训练。可从项目助理、筛查执行开始，逐步发展为测评／访谈专员、项目专员和项目经理。

这些工作会出现在哪里？

园内 / 学校 / 教培专委会及合作机构心理工作室街道社区企业个人与家庭

园内 / 学校 / 教培机构心理活动、家长课堂、团体协同、项目服务；达到要求后的个体与家庭服务。常见固定岗位、兼职、机构采购或项目合作。

专委会及合作机构讲座、团辅、测评访谈、项目执行、机构合作咨询。常见项目制、按次/场、机构合作。

03

FROM LEARNING TO DOING

怎样从“学过”走向“会做”？

课程与实践交替进行。真正的变化，是从课堂里的模拟任务，走向有支持、有记录、有反馈的真实服务。

G1 · 心理入门

课堂上练过

建立共同底座，完成模拟初访、基本会谈、转介考核与入门作品。

初阶连接：课程助教、活动协助、项目助理等适配任务。

G2 · 心理实务

在督导下做过

参与真实任务，学习需求评估、协同交付、服务记录、客户反馈、异常上报与项目复盘。

成果证据：实践记录、协同交付经验、督导与客户反馈。

G3—G5 · 专修与精进

形成主专业

通过方向专修、持续实践与方向考核，逐步承担更复杂的服务、课程或项目。

长期发展：专项服务、课程研发、项目管理，直至督导、师资与质量负责。

从入门到独立服务，中间不是空白。助教、活动协助、项目助理、协同交付和受督导实践，都是一段段可完成的台阶；真实项目中还有主责专业人员、督导与复盘支持，帮助你把每次经历变成下一次进阶的证据。

这四个环节，就是我们陪你从学习走向实际任务的路径。先积累作品与能力，再通过评价、人才角色和项目匹配逐步扩大任务范围；每次实践都以有准备、有支持、有反馈为目标。
长期发展支持包括什么？
  • 个人成长档案与阶段适配反馈；
  • 后续方向专修和持续学习；
  • 实践、主责专业人员与督导机制；
  • 成熟专业框架参考及外部认证信息支持；

参与真实项目时，我会得到哪些支持？

项目会明确主责专业人员、任务内容与服务边界，并按项目条件配置督导。你可以围绕需求理解、协同交付、服务记录、异常上报和复盘持续获得反馈。

这些经历会继续沉淀到成长档案中，成为后续方向专修、角色进阶和项目匹配的依据。

关于转型、证书与实践，六个具体问题

跨行业可以学吗？原有经验还有用吗？

可以，而且原有经历不必清零。重要的是找到经历与心理服务任务之间的连接：

  • 教师、幼师、教培人员：可以优先了解心理讲师、家长课堂、团体活动等方向，把教学与沟通经验迁移过来。
  • 社工、社区及项目工作者：可以重点了解测评访谈、社区心理服务、团体协同与项目执行。
  • 擅长组织、沟通、数据的人：项目服务线能承接这些能力，再补心理测量、访谈与项目交付训练。
  • 希望长期深耕个体／家庭服务的人：可以从 G1 咨询主线起步，继续走向受督导实践与咨询专修。

这些不是给你贴标签，而是帮你找到第一段可迁移的优势。G1 先打共同底座，G2 结合真实任务继续确认适配，G3 再形成主专业；不需要在报名前一次性决定长期方向。

首期学完后，怎样一步步走向独立咨询？

首期的价值，是让你真正踏上咨询成长路径。你会完成共同理论学习与线下 5 天实训，练习初访流程、基本会谈、识别转介，并留下作品、考核反馈和成长档案。

接下来的路线是：G1 咨询入门 → G2 在主责人员与督导支持下参与真实任务 → G3 咨询方向专修 → 短程咨询 → 中长程与专项。你会先掌握可以练、可以评的基础能力，再按实践与胜任情况逐步增加任务难度；独立咨询是后续持续训练和实践要达成的目标，首期负责把第一段路走实。

有证书吗？除了证书还能带走什么？

有相应的证书与学习成果安排，而且成果不止一张证。可以分三类理解：

  • 外部证书：由相应第三方按规则评价和颁发，名称、发证主体与适用范围以当期招生文件为准。
  • 学会结业证明：对应相应学习与结业要求。
  • 课程能力评价与成长档案：记录阶段作品、考核反馈，以及后续实践与督导成果。

在整套培养体系里，证书是学习成果的一部分；作品、实践和督导记录会继续帮助你进入 G2、选择 G3 方向，并作为后续人才角色与项目匹配的依据。报名前可以逐项了解每类成果的评价方式和用途。

有实践机会吗？你们能提供哪些岗位或任务？

有。实践与岗位连接本来就是整套培训体系的一部分，而不是课程结束后的附加话题。随着阶段与能力提升，可以接触的任务包括：

  • 入门阶段：课程助教、活动协助、项目助理、筛查／资料收集助理等。
  • 心理实务阶段：指定模块试讲、协同团体、测评访谈、项目执行、初访接待与资料整理等；咨询方向在主责人员和督导支持下开展适配实践。
  • 方向专修及以后：标准心理科普讲师、结构化心理教育团体主带、测评／访谈专员、项目专员等，并继续向专题讲师、课程研发、专项服务、项目经理及机构合作咨询发展。

这些任务可以出现在专委会及合作机构、园内／学校／教培、心理工作室、街道社区、企业等场景。我们会依据你的作品、考核和方向，将进入相应人才角色的学员与适配真实项目进行匹配；具体任务随项目开放，并明确主责人员、督导与交付要求。实践后的记录和反馈还会继续支持你的下一次进阶。

后续四条方向，分别怎样学习和进阶？
  • 心理咨询：G1 咨询入门 → G2 受督导实践 → G3 咨询专修 → 短程咨询 → 中长程与专项。
  • 心理讲师：共同底座 → 讲师实务与教案、试讲作品 → 助教／协同讲师 → 标准讲师 → 专题讲师与课程研发。
  • 心理团辅：共同底座 → 团体方案与协同演练 → 活动协助／协同带领 → 结构化团体主带 → 专项团体。
  • 测评访谈与项目：测量与访谈基础 → 项目交付训练 → 项目助理 → 测评／访谈专员、项目专员 → 项目经理。

你可以先在 G1 广泛理解，再结合 G2 的任务体验与反馈确定主方向。四条路不必都学，也不把咨询当成唯一出口；后续课程会围绕你选定方向需要承担的真实任务继续展开。

收入可以怎样一步步提高？

可以把收入理解为能力与任务逐步增长的结果，而且这条增长路径可以拆解、可以努力。你的路径可以分成三段：

  • 先进入任务：从助教、活动协助、项目助理等适配工作开始，理解真实服务怎样交付。
  • 再扩大角色：通过 G2 实务与反馈，逐步参与协同讲师、协同团体、测评访谈和项目执行，积累按辅助、协同、人次或项目计酬的机会。
  • 形成主专业：通过 G3 专修与持续实践，逐步承担短程咨询、标准讲座、结构化团体主带或项目专员等任务，合作方式可扩展到按次、场、天、项目或机构岗位。
